# UC02 申请认领学者门户

**版本**：v1.1（按 B1 SRS 对齐）　**负责人**：A4　**来源**：A3 用例清单、作业 1 的 R05、B1 SRS FR-27/IF-11/DR-09　**优先级**：Must

| 项目 | 规约 |
| --- | --- |
| 主参与者 | 科研人员（申请人，ACT02） |
| 目标 | 申请本人学者门户的管理权，形成可审核、可追溯的申请，不因提交而自动获得权限 |
| 触发 | 申请人在本人门户页面选择“申请认领” |
| 前置条件 | 平台能识别并回访该申请人；目标门户存在且可申请。具体账号登录或校内身份接入方式尚未确定，不在此假定已接入第三方系统 |
| 成功后置条件 | 平台生成申请编号、提交时间、申请人标识、目标门户标识、佐证材料引用及 `submitted` 状态；后续进入 `verifying`，申请人可查看受理状态；管理员可见待处理记录 |
| 最低保证 | 未审核通过前不授予门户管理权限；佐证材料仅向有权审核人员开放；提交失败不留下误导性的“已受理”提示 |

## 主成功流程

1. 申请人检索并查看目标学者门户，确认姓名、机构、领域等公开信息与本人相符。
2. 平台显示当前认领状态、申请说明、需要填写的最小信息和佐证材料类别；材料类别、保存期限和具体核验方法由后续管理员访谈确定。
3. 申请人填写可联系的身份信息，上传或提供本人身份佐证，确认目标门户并提交。
4. 平台校验必填信息、文件/链接格式和同一申请人对同一门户的未完结申请；不对身份真实性作自动通过结论。
5. 平台保存申请及佐证材料的访问控制记录，生成唯一申请编号，登记提交时间与申请人标识。
6. 平台把申请置于 `submitted`，送入验证队列后转 `verifying`，向申请人显示受理编号、当前状态和后续查看入口；此时不授予门户管理权。

## 备选与异常流程

| 编号/接入点 | 条件 | 系统行为与结果 |
| --- | --- | --- |
| A1／步骤 1 | 平台尚无目标学者门户 | 提示未找到可认领门户，允许申请人记录线索或等待后续采集；“新建门户申请”是否支持待产品评审，不能自动造出已核实的学者身份 |
| A2／步骤 1—3 | 同名、跨机构或信息冲突 | 展示足够区分的公开字段；申请人需明确选定目标；无法确认时不提交到错误门户 |
| A3／步骤 2—4 | 目标门户已有有效管理人或存在冲突申请 | 阻止直接认领，提示进入争议/人工核验路径；不得暴露他人的非公开佐证 |
| A4／步骤 4 | 材料缺失、格式不符或与目标不一致 | 标明需补充的字段；允许修正后再次提交；不生成“已受理”成功状态 |
| A5／步骤 4 | 同一申请人重复提交未完结申请 | 返回原申请编号和状态，不创建重复待审记录；是否允许补正由认领状态图及 SRS 决定 |
| A6／步骤 5 | 保存失败或服务不可用 | 告知未受理并允许稍后重试；不得出现申请编号已显示但后台无记录的情况 |

## 业务规则与数据要求

- BR-UC02-01：**门户认领**授予本人门户管理资格；它不自动证明申请人拥有或独占外部数据库里的每条成果。
- BR-UC02-02：申请至少关联申请人、目标门户、佐证材料引用、提交时间、状态与状态变化记录；具体敏感字段、保留期限和删除策略由安全/合规章节确定。
- BR-UC02-03：申请必须进入验证与管理员审核流程；只有 UC03 明确通过后才能开通管理权限。
- BR-UC02-04：同一申请人对同一门户的未完结重复请求不得造成多份可独立通过的申请。
- BR-UC02-05：认领状态名称、补正和撤回规则须与课程要求的认领申请状态图保持一致。
- BR-UC02-06：本版状态按 B1 SRS 为 `submitted → verifying → approved/rejected`，申请人可取消为 `cancelled`；驳回后可补证重提。状态机是设计规则，不代表学校已有同名审批流程。

## 可验收场景

1. **正常提交**：给定一个尚可申请的门户与完整材料；当科研人员提交；则生成申请编号和待审状态，而该人员不能编辑门户。
2. **材料不完整**：给定缺少必填佐证；当提交；则明确指出缺失项且不显示已受理。
3. **重复申请**：给定同一人对同一门户已有未完结申请；当再次提交；则显示既有编号与状态，不产生第二条独立待审记录。
4. **同名冲突**：给定同名学者属于不同机构；当申请人选择门户；则页面显示区分信息并记录确切目标门户标识，不按姓名自动匹配。

## 与后续模型的接口

UC03 接收本用例生成的待审核申请；认领审核活动图描述“提交→验证→审核→通过/驳回”；认领状态图沿用 B1 SRS 的状态名并定义取消、驳回重提及争议处理。**待实证确认**：申请人识别方式、佐证材料清单、隐私保留期限、无门户时能否创建候选门户。这些不能从作业 1 的学生问卷或 B5 AI 推演直接裁定。
