# UC04 检索并查看成果

**版本**：v1.0　**负责人**：A5　**基线**：A2 用例图、B1《SRS》FR-13—FR-20、IF-04/05/10、DR-02/04、NFR-03/11/12　**优先级**：Must

| 项目 | 规约 |
| --- | --- |
| 主参与者 | 访客（ACT01）；认证成员、已认领学者和管理员也可按各自权限执行 |
| 目标 | 在本人可读范围内检索成果，辨识目标记录、版本、来源、附件权限和可用引用 |
| 触发 | 用户输入关键词或选择筛选条件并提交检索，或打开一条结果 |
| 前置条件 | 平台检索服务可用；匿名用户仅访问公开记录；分类、来源与发布状态已按 SRS 建模 |
| 成功后置条件 | 页面返回本次可读结果、条件、总数/分面、排序与分页信息；打开详情显示获准版本、来源及可读入口；若执行引用/导出，生成与已核验字段一致的内容 |
| 最低保证 | 不因查询失败显示“零收录”；不可读记录不进入结果数、分面、详情、附件、引用或导出；无全文授权时不提供代下载 |

## 主成功流程

1. 用户输入关键词，按类型、学术领域、作者、机构、年份等维度选择条件。平台显示已选条件；维度间 AND、同维度多选 OR。默认成果年度为 `publication_year`，未知年度单列。
2. 平台校验输入并依据当前身份先过滤可读且已发布的记录，再执行检索、总数与分面计算。检索覆盖 B1 SRS 的七类成果：论文、专利、软件著作权、获奖、项目、课程材料、未发表手稿；其中未发表手稿仅在实际可读范围内出现，匿名用户不得因类型存在而看见私有内容。
3. 平台按相关度排序；用户可切换年度或有来源的已知被引数。有效 DOI 精确命中优先，同分按成果年度和稳定 ID 排序。默认每页 20 条、最大 100 条，返回条件、页码、总数与分面。
4. 用户打开目标成果。平台重新鉴权，展示当前获准版本、类型专属字段、作者/机构、来源、获取时间、字段核验状态及适用的年度口径。DOI/关键词缺失按字段状态显示，不填造。
5. 平台区分元数据读取与附件读取权：仅显示已通过检查且获授权的附件入口；外部来源链接保持真实来源名称，不把其他站点标成知网。
6. 用户选择引用文本时，平台根据当前可读且已核验题录生成适用文本。论文可按 SRS 规定的 GB/T 7714-2015 模板和 BibTeX；其他类型按其类型名称与适用编号生成，不伪装为论文或专利。
7. 用户选择批量导出时，平台按调用时权限与当前发布版本导出 CSV/BibTeX 元数据，最多 1000 条且不含附件；返回实际导出条数和格式。CSV 危险公式前缀按 SRS 安全文本规则处理，业务原值保留。

## 备选与异常流程

| 编号/接入点 | 条件 | 系统行为与结果 |
| --- | --- | --- |
| A1／步骤 1 | 条件格式错误或超出允许页大小 | 指明需修改的条件，不执行误导性检索；分页上限按 IF-04 |
| A2／步骤 2 | 查询成功但无可读命中 | 显示“当前条件下无匹配”与放宽条件提示，结果数为 0；不披露受限记录数 |
| A3／步骤 2—3 | 检索服务失败、超时或部分索引不可用 | 显示查询失败及可重试入口，记录请求 ID；不得伪装成明确零结果 |
| A4／步骤 4 | 记录已下架、删除、版本变化或当前用户无权 | 服务端统一返回不可见结果（SRS 对象级 404）；不泄露题名或曾经存在性 |
| A5／步骤 5 | 有权读元数据，但无权下载附件或附件未通过安全检查 | 保留获准元数据展示，附件入口不可用并给出权限/状态说明，不提供绕过链接 |
| A6／步骤 6 | 引用必需字段缺失、未核验或来源不支持对应格式 | 明示缺失/待核验及可用格式；不虚构 DOI、页码、年份或来源，不以其他来源冒充知网导出 |
| A7／步骤 7 | 导出超过 1000 条或 10MB、部分选中项无权 | 按 FR-20/IF-10 拒绝超限并提示缩小范围；有权项按当前版本处理，无权项不泄露内容；失败不产生误导性“导出成功” |

## 业务规则与数据要求

- BR-UC04-01：过滤与统计先鉴权再计算，检索、详情、附件、引用、导出和门户显示同一读取边界；权限收窄或下架后不能从旧索引/缓存取回内容。
- BR-UC04-02：平台设计覆盖七类成果；作业 1 的四类公开走查证据只证明其调研范围，不证明其他三类已有可用数据。缺数据时显示覆盖范围，不删去 B 组规定的类型能力。
- BR-UC04-03：查询结果状态至少区分“有结果、明确零结果、查询失败、权限不足、尚未采集”。对象级无权/不存在按 SRS 统一处理，不在错误信息中暴露记录存在性。
- BR-UC04-04：论文引用格式与批量导出按 FR-19/20、IF-10 执行；生成内容只用当前可读、已核验字段，且不得复制无授权全文。
- BR-UC04-05：作者同名不自动合并，DOI 只在有效且已核验时参与精确置前；被引数未知与数值 0 分开。

## 可验收场景

1. **组合检索**：给定七类记录及不同机构/年度；当用户组合筛选；则维度间 AND、同维度多选 OR，条件和可读分面可复算（对应 FR-13/14、AC-US-13/14）。
2. **失败与零结果**：给定一次合法空响应和一次检索故障；当分别检索；则前者显示 0 与范围，后者显示失败和请求 ID，不能混同。
3. **权限一致**：给定 private 成果及已撤回记录；当访客检索、猜 ID、导出；则均不泄露记录及其分面计数（FR-17、AT-03/10）。
4. **引用与批量导出**：给定缺 DOI 的论文、含公式前缀的题名以及超过 1000 条的选择；当生成引用/CSV；则缺值不补造、危险前缀安全处理、超限拒绝（FR-19/20、AT-11）。

## 与后续规范及图的接口

UC04 覆盖 A2 的“检索并查看成果”椭圆；FR-13—FR-20 是其主流程和扩展流程，不要求再增画多个用例。检索排序、权限过滤、引用模板和导出安全处理应在 SPEC 中细化。本规约将 B1 SRS 作为设计基线；具体七类数据的真实可用量仍须以验收数据和来源授权证明，不以作业 1 的走查外推。
