# UC05 管理本人已认领成果

**版本**：v1.0　**负责人**：A5　**基线**：A2 用例图、B1《SRS》FR-01—FR-12/FR-27、IF-06/08/09/11/15、DR-01/05—09、NFR-03/06/11/12　**优先级**：Must

| 项目 | 规约 |
| --- | --- |
| 主参与者 | 已认领学者（ACT03），属于有明确门户及成果编辑授权的认证成员 |
| 相关参与者 | 初审教师、授权终审管理员按 B1 SRS 的审核职责处理提交版本；他们不是本用例的主参与者 |
| 目标 | 维护本人获授权的学者门户与关联成果，提交新增或更正并查看审核结果，同时保留来源、版本及共同作者权益 |
| 触发 | 已认领学者打开本人门户，选择新增成果、修正信息或查看处理状态 |
| 前置条件 | UC02/UC03 对目标门户的认领已批准且权限有效；对象属于本人可管理范围；账号认证与版本信息有效 |
| 成功后置条件 | 新增/修改形成可追踪草稿或待审版本，含责任人、来源、变更、时间和状态；审核通过后才按可见范围发布；旧发布版在新版本通过前保持原获准内容（紧急收窄/下架除外） |
| 最低保证 | 不编辑他人门户或成果；不因同名、共同署名自动授予独占控制权；失败与冲突不覆盖已发布版本、外部原始值或他人授权 |

## 主成功流程

1. 学者打开本人门户；平台核验登录身份、认领关系及具体记录的编辑权限，展示获准的门户信息、已关联成果和待处理申请。
2. 学者选择新增七类中的一种成果，或选中已有成果的当前版本。平台展示类型专属字段、来源、作者顺序、可见范围及历史差异；已有来源原值与平台规范值分别呈现。
3. 学者填写或修正本人有权维护的字段，关联共同作者/机构，提供可核查来源或附件授权依据。系统允许 DOI/关键词等可空字段留空，但记录字段状态；人工送审的年度按 SRS 校验。
4. 平台校验格式、来源、附件大小/类型和权限。相同 DOI、相似题名或同名作者只生成候选提示，不自动合并人物或成果；与外部已核验字段冲突时保留原值并生成差异待核验。
5. 学者保存草稿并查看预览，确认后提交审核；平台以版本号和幂等键保存提交快照及审计。公开内容、署名、附件或放宽可见范围的修改建立新版本，不原地覆盖旧发布版。
6. 平台按 SRS 路由初审与终审：合格署名初审教师可处理适用记录；无合格教师或教师本人提交时直接进入授权管理员复审；终审者不能批准本人提交或有利益冲突的版本。
7. 通过后平台原子切换获准版本，按授权范围更新门户与检索；若退回则保留理由与可修改版本，学者能查看状态并再次修正。所有来源、版本与审核链保留。

## 备选与异常流程

| 编号/接入点 | 条件 | 系统行为与结果 |
| --- | --- | --- |
| A1／步骤 1 | 认领未批准、被撤销、账号失效或目标不属于本人 | 拒绝编辑和读取非公开内容；不根据同名猜测授予权限 |
| A2／步骤 2—4 | 同名作者、共同作者争议或疑似重复成果 | 只给候选与差异；平台不得自动独占/合并，转核验任务，原来源和署名保持 |
| A3／步骤 3—4 | 缺少必填字段、年度格式不符、附件无授权或安全检查失败 | 指出字段与原因；可保留合法草稿，但不得送审/公开不合格内容；附件隔离不提供下载 |
| A4／步骤 5 | 保存失败、同幂等键异内容或旧版本提交 | 返回明确失败/409，保留当前有效版本；重试不重复创建成果或审核记录 |
| A5／步骤 6—7 | 审核退回或驳回 | 展示获授权的处理理由，版本状态为 returned；学者可修正并重新提交，不把退回版混入公开检索 |
| A6／步骤 5—7 | 学者请求收窄可见范围、撤回或删除 | 收窄与下架按 SRS 即时撤销读取；撤回/删除走 IF-15 的授权与审计，不将逻辑删除表述成所有副本已物理清除 |
| A7／步骤 7 | 新版审核通过时索引更新延迟或通知失败 | 服务端读取先按当前授权和发布版本执行；不能向无权人返回旧内容。通知失败不抹掉已完成审核事实 |

## 业务规则与数据要求

- BR-UC05-01：门户认领赋予目标门户管理资格，不等于对所有同名成果、共同作者成果或外部数据库记录拥有独占权。成果编辑还需记录级授权。
- BR-UC05-02：成果支持 B1 SRS 的七类类型；类型专属字段和附件授权按 FR-02、DR-01、NFR-05/11。作业 1 未取得软著、课件逐件证据，不得把模型能力写成已收集到具体条目。
- BR-UC05-03：公开内容编辑建新版本并重审；可见范围收窄立即生效，放宽须审核。版本、署名、来源、原始值和差异链可追溯。
- BR-UC05-04：User 与 Person 分离，共同作者多对多；账号审核通过的本人身份关联不让其覆盖其他作者的声明。
- BR-UC05-05：审核、附件和导入与权限矩阵一致；操作、结果和理由进入审计，不在公共门户暴露认证佐证。

## 可验收场景

1. **本人修改**：给定已认领学者和本人可编辑的已发布成果；当其补充 DOI 并提交；则生成待审新版本，旧发布版不原地改变（FR-10、AC-US-10-01）。
2. **共同署名**：给定两名共同作者；当其中一人认领本人身份；则另一人署名及权限不被覆盖，身份关联仍可分别核验（FR-05/08、DR-01）。
3. **越权与冲突**：给定他人门户、过期版本或相似题名；当学者尝试编辑；则越权拒绝、旧版冲突 409、相似项只提示候选（AT-03/08/09）。
4. **审核与撤回**：给定公开成果更新并退回；当学者查看并修订；则旧版继续按获准范围显示，退回版不公开；收窄或下架后旧链接不能读取（AT-10）。

## 与后续规范及图的接口

UC05 对接 UC02/UC03 的认领结果和 B1 的成果审核链，A2 图中“管理本人已认领成果”作为总用例，其提交、审核、版本更新、撤回均是内部/扩展流程。B1 SRS 对初审/终审、版本和七类类型的规则为本版设计基线；具体学者可编辑哪些外部来源字段仍须由业务方与授权证明确认。
