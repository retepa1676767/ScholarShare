# 认领审核活动图与两张状态图说明

本目录提供三份可编辑 Mermaid 图源和对应 PNG：`A1-认领审核活动图`、`A1-采集任务状态图`、`A1-认领申请状态图`。图依据 B1 SRS 2.2、FR-25/27、A4 UC01—UC03 编写，PNG 由 `../04-构建脚本与样本/render_a1_diagrams.py` 生成并已做图面检查。A2 用例图按用户要求使用 CodeArts 工程；这三张图目前是本地绘制的交付图，未宣称为 CodeArts 导出。

- 认领活动图覆盖提交、校验、核验、管理员决定、通过/驳回与权限生效，证据不足和已有管理人时禁止直接通过。
- 采集状态图用 B1 命名 `queued/running/succeeded/failed/retrying/stopped`，失败重试最多 3 次；成功 0 条与失败分开。
- 认领状态图用 B1 命名 `submitted/verifying/approved/rejected/cancelled/disputed`。驳回补证重提在图中回到 submitted，表示新处理轮次，不暗示复用旧审核记录。`disputed` 后续如何恢复或终结，B1 SRS 尚未定义，图中不编造转移。

图已与 A4 三份规约、B1 SRS 的英文状态名及 A1 追溯矩阵核对。若课程另要求这三张图也必须在 CodeArts 绘制，应在 CodeArts 中复刻并导出图像；当前 `.mmd` 与渲染脚本保留可编辑建模来源。
