# US-02 成果类型登记

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望按不同成果类型登记，以便使用适合该类型的字段。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：任务书明确列举论文、专利、项目、获奖；B2原稿另含软件著作权、课程材料、未发表手稿。
- SRS对应：FR-02。

## 业务规则

一级类型固定为论文、专利、软件著作权、获奖、项目、课程材料、未发表手稿共7类；论文另有期刊/会议/学位论文子类型。管理员维护展示顺序和分类，不允许普通用户自造类型。

## 验收标准

### AC-US-02-01

Given 打开成果登记页。

When 展开类型选项。

Then 显示上述7类，其中专利有专利号及授权日期字段。

### AC-US-02-02

Given 选择获奖。

When 刷新表单。

Then 颁发机构和奖项名称为该类型必填，缺失会阻止提交。

### AC-US-02-03

Given 选择论文。

When 刷新表单。

Then 显示出处、卷期页、DOI字段；DOI不是必填。

### AC-US-02-04

Given 某类成果已经发布且用户有读取权限。

When 打开详情及按类型筛选。

Then 详情显示正确类型，检索返回该类型的可读成果。
