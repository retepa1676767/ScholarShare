# US-04 附件与佐证材料

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望上传附件并设置授权，以便提供可核对的佐证且防止泄露。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B2 US-04与B4 NFR-05、IF-08，冲突统一记录在SRS附录。
- SRS对应：FR-04。

## 业务规则

仅接收PDF、PNG、JPG/JPEG；单文件不超过20MB，每条成果最多5个。ZIP及可执行文件不接收。实际类型与扩展名均检查；隔离检查失败的文件不能下载或全文索引。附件范围不得宽于成果。

## 验收标准

### AC-US-04-01

Given 成果草稿存在且选择不超过20MB的真实PDF。

When 确认上传并通过安全检查。

Then 附件与该版本关联；仅具备权限的用户可预览或下载。

### AC-US-04-02

Given 文件超过20MB或已有5个附件。

When 确认上传。

Then 被拒绝并说明上限，不增加附件关联。

### AC-US-04-03

Given 文件为ZIP、EXE或伪装PDF。

When 确认上传。

Then 格式不允许或检测失败；提供允许格式列表，危险文件隔离。

### AC-US-04-04

Given 附件只允许院内成员。

When 访客通过原始附件地址请求下载。

Then 返回统一不可见结果且不泄露内容。
