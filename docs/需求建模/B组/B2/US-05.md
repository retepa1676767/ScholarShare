# US-05 共同作者与署名

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望登记共同作者和署名顺序，以便准确展示贡献与身份。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B2原稿；B5通讯作者验收补充；B4 DR-01。
- SRS对应：FR-05。

## 业务规则

Person与User分离；外部作者无需账号。登记至少1位作者，保存署名顺序、机构和通讯作者标识；同名不自动绑定身份。

## 验收标准

### AC-US-05-01

Given 已有3位作者。

When 将第3位调至第1位并保存。

Then 详情按新顺序显示且版本记录保留修改。

### AC-US-05-02

Given 署名有可审核且不是提交者本人的教师。

When 提交审核。

Then 其初审队列显示本次提交版本，并向相关教师发送待审通知。

### AC-US-05-03

Given 作者列表为空。

When 提交。

Then 被阻止并提示至少1位作者。

### AC-US-05-04

Given 共同作者没有账号。

When 填写姓名及单位并保存。

Then 允许建立人员记录，不强制该作者注册。

### AC-US-05-05

Given 编辑论文作者关系。

When 标记通讯作者并保存。

Then 标记随作者关系显示，非仅保存在页面状态。
