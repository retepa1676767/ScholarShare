# US-08 成果作者关联认领

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：学生或教师等认证科研人员
- 用户故事：作为学生或教师等认证科研人员，我希望申请认领代录成果中的本人作者身份，以便将成果关联到个人门户。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B2原稿、B5争议推演；任务书明确要求身份认领审核。
- SRS对应：FR-08。

## 业务规则

自动姓名匹配只生成候选，不自动授予控制权。认领的是作者Person身份而非整条成果独占权；多人合著可分别认领本人。机构/认证证据与管理员审核通过后才生效；门户认领另见FR-27。

## 验收标准

### AC-US-08-01

Given 公开成果有未绑定账号的本人作者候选。

When 认证用户打开详情。

Then 显示申请认领本人作者身份入口。

### AC-US-08-02

Given 认领申请附有身份证据。

When 授权管理员审核通过。

Then 关联到申请人门户并记录审核人和理由，未经审核不生效。

### AC-US-08-03

Given 另一个账号申请同一Person身份。

When 系统检查已绑定关系。

Then 进入冲突处理且不覆盖旧关系；不同共同作者认领不被误拒绝。

### AC-US-08-04

Given 认领发生争议。

When 管理员核验并解除错误关联。

Then 保留处理意见和历史，不删除其他共同作者关系。
