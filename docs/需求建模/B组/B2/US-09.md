# US-09 批量导入成果

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：教师或授权导入成员
- 用户故事：作为教师或授权导入成员，我希望预览并批量登记合法来源元数据，以便降低逐条登记成本。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。

- SRS对应：FR-09。

## 业务规则

首版接收UTF-8 CSV模板和标准BibTeX .bib，不接收未定义语法的知网 .txt。单次1000条、10MB；先预览后确认。历史未知年度留草稿，待补后送审；不得自动发布或自动覆盖。

## 验收标准

### AC-US-09-01

Given 上传含20条完整论文的标准BibTeX。

When 预览完成。

Then 显示20条题名、作者、年份和出处，逐行状态可见。

### AC-US-09-02

Given 20条中3条年份未知。

When 确认导入。

Then 记录写入草稿；17条可送审，3条标为待补年份且无法送审；失败与未知不混用。

### AC-US-09-03

Given 某行与已有成果疑似重复。

When 确认导入。

Then 显示候选及来源，由授权用户跳过或说明原因保留，重试不重复写入。

### AC-US-09-04

Given 批次完成。

Given 文件不是CSV/BIB、超过10MB或超过1000条。

When 上传或确认。
