# US-10 已发布成果版本更新

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：有编辑权的认证成员
- 用户故事：作为有编辑权的认证成员，我希望修正已发布信息，以便保留准确数据与审核记录。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B2 US-10与B4 NFR-03、DR-06。
- SRS对应：FR-10。

## 业务规则

公开内容、附件、署名、可见范围放宽的修改均产生新草稿版本并重审；不原地覆盖已发布版本。收窄范围立即生效不需等待，版本留痕。旧版在新版本通过前保持原范围可读，紧急下架除外。

## 验收标准

### AC-US-10-01

Given 已发布记录的DOI为空。

When 编辑补充并提交。

Then 建立待审新版本，旧公开版不直接改动，新版通过后显示DOI且留痕。

### AC-US-10-02

Given 修改署名顺序。

When 提交新版本。

Then 按规则进入初审/复审；旧版在审核期间继续显示，不把新署名误展示为已确认。

### AC-US-10-03

Given 用户无编辑权。

When 访问编辑接口。

Then 被拒绝且版本不变。

### AC-US-10-04

Given 管理员查看历史。

When 展开版本差异。

Then 显示字段旧值新值、操作者、时间及对应审核意见。
