# US-11 撤回与删除申请

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：成果提交者
- 用户故事：作为成果提交者，我希望撤回待审稿或申请移除已发布内容，以便纠正误传并控制展示。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B2 US-11；B4 DR-08。
- SRS对应：FR-11。

## 业务规则

待审可撤回为草稿并关闭任务；公开记录删除申请即进入临时隔离，不继续公开敏感内容，授权管理员确认后逻辑删除。物理清理由保留策略管理，不自动删除审计。

## 验收标准

### AC-US-11-01

Given 成果仍待审。

When 提交者撤回。

Then 状态草稿，关闭旧版本审核任务且发送通知。

### AC-US-11-02

Given 成果已发布。

When 提交者申请删除。

Then 创建申请并暂停公开检索、附件和导出，管理员确认后变为已删除。

### AC-US-11-03

Given 删除确认完成。

When 普通用户访问原详情链接。

Then 返回统一不可见结果，不返回旧附件。

### AC-US-11-04

Given 管理员查归档。

When 查已删除记录。

Then 依法保留的版本、原因和操作记录可查，普通用户不可读。
