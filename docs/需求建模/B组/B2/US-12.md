# US-12 成果可见范围

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望设置公开、仅院内或仅自己，以便避免未发表内容未经授权传播。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B2 US-12与B4数据权限规则；未发表保密诉求是设计推演。
- SRS对应：FR-12。

## 业务规则

public、members、private固定3档；members限所属机构已认证成员；private限提交责任人及为处理该记录而获授权审核人，不因共同署名自动授予读取权。草稿与退回不因设置public而公开。

## 验收标准

### AC-US-12-01

Given 新建未发表手稿。

When 打开表单。

Then 默认private，改为公开必须经过授权检查和审核。

### AC-US-12-02

Given 已发布记录为members。

When 访客或院外账号请求检索/详情。

Then 条目不可见且返回统一不可见结果。

### AC-US-12-03

Given private成果有共同作者但未单独授权。

When 该共同作者检索或请求详情。

Then 不展示题名、摘要、附件或提示片段。

### AC-US-12-04

Given 已发布private成果要放宽为public。

When 保存并提交。

Then 在审核通过前继续private；已公开成果收窄立即生效。
