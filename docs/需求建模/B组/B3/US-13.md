# US-13 跨类型统一检索

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：访客或认证成员
- 用户故事：作为访客或认证成员，我希望使用关键词搜索全部可读成果，以便快速找到目标。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：任务书检索查看；B1矩阵公开渠道比较，结论以复核边界为限。
- SRS对应：FR-13。

## 业务规则

标题、作者、关键词、摘要及适用编号参与检索，包含7类成果。先权限过滤再计算总数/分面；有效DOI精确匹配置前，不承诺未去重数据唯一。

## 验收标准

### AC-US-13-01

Given 公开库有7类成果。

When 检索同时出现在论文与获奖题名的词。

Then 返回两类可读命中，按7类显示分面计数。

### AC-US-13-02

Given 作者位于不同署名位置。

When 输入姓名检索。

Then 可读结果包含非第一作者成果，不自动合并同名人员。

### AC-US-13-03

Given 库内有一条已核验DOI的公开论文。

When 按该DOI精确检索。

Then 目标排在模糊命中前，重复候选有明确标记。

### AC-US-13-04

Given 关键词无可读命中。

When 打开结果页。

Then 显示无匹配及放宽条件提示，不泄露不可读记录数。
