# US-14 组合筛选与高级检索

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：访客或认证成员
- 用户故事：作为访客或认证成员，我希望组合作者、机构、年份和类型条件，以便缩小结果范围。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：任务书分类过滤；B3原稿。
- SRS对应：FR-14。

## 业务规则

不同维度用AND，同一维度多选用OR。默认成果年度publication_year；来源分组年度需指定来源，未知年份单列。不得把知网列表日期替代出版年。

## 验收标准

### AC-US-14-01

Given 命中120条。

When 选软件著作权并限定2023至2026年。

Then 仅返回同时满足类型及年度的可读记录。

### AC-US-14-02

Given 已选作者。

When 再选所属单位。

Then 按AND组合，移除条件前不扩大到OR。

### AC-US-14-03

Given 已有3个条件。

When 移除1个标签。

Then 保留关键词并按剩余条件重新计算。

### AC-US-14-04

Given 某类型无命中。

When 应用条件。

Then 显示0条与清除条件入口，不报错且不泄露隐藏数据。
