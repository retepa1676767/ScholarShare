# US-17 全链路权限一致

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：平台管理员
- 用户故事：作为平台管理员，我希望让可见范围在各入口一致，以便杜绝旁路泄露。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3 US-17；B4 NFR-03/11。
- SRS对应：FR-17。

## 业务规则

检索、分面、详情、附件、引用、导出、统计、门户、全文和通知统一鉴权；收窄和下架即时撤销读取，不等待异步索引或浏览器缓存。

## 验收标准

### AC-US-17-01

Given 记录为private。

When 非责任人按关键词、DOI或附件地址访问。

Then 所有入口均不返回记录及片段。

### AC-US-17-02

Given members记录的元数据或附件导出。

When 访客请求导出。

Then 不导出且不泄露被跳过对象的题名。

### AC-US-17-03

Given 记录从公开改为private或下架。

When 再次使用旧链接及缓存查询。

Then 服务端重新鉴权立即拒绝，旧索引不得绕过。

### AC-US-17-04

Given 管理员处理受限记录。

When 使用其授权后台查看。

Then 只在处理范围可读，访问日志留痕不默认公开。
