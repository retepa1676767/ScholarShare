# US-18 作者聚合与姓名消歧

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：访客或认证成员
- 用户故事：作为访客或认证成员，我希望查看正确作者的成果，以便区分同名研究者。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：任务书门户；B3 ORCID比较及B4人员数据结构。
- SRS对应：FR-18。

## 业务规则

按Person稳定ID聚合；经验证ORCID与已审核账号关联可协助识别，姓名+单位只生成候选；未经核验的工号不得成为自动合并依据。

## 验收标准

### AC-US-18-01

Given 两名同名作者分别有不同稳定ID。

When 打开其中一人的门户。

Then 只显示该Person关联的可读成果。

### AC-US-18-02

Given 人员已审核关联ORCID。

When 从ORCID或账号定位。

Then 展示关联身份来源，不自动覆盖不一致的人员关系。

### AC-US-18-03

Given 只有相同姓名和单位。

When 导入新作者。

Then 显示候选而不自动合并，授权人员核验后留痕。

### AC-US-18-04

Given 该人员关联private成果。

When 访客查看其门户。

Then 该成果及数量不暴露。
