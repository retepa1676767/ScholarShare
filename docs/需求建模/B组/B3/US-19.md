# US-19 引用格式与复制

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：访客或认证成员
- 用户故事：作为访客或认证成员，我希望生成可复制引用文本，以便减少手工拼接错误。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3 US-19；B4导出要求。
- SRS对应：FR-19。

## 业务规则

论文支持组员指定的GB/T 7714-2015模板和BibTeX，并以人工核对的模板样例验收；不宣称对每种类型均完成正式标准认证。专利/软著等生成带类型名称及适用编号的成果引用文本，不把软著误标成专利或软件出版物。

## 验收标准

### AC-US-19-01

Given 论文作者、题名、出处和年份齐全且已有人工核对的模板样例。

When 选择GB/T 7714-2015论文模板生成引用。

Then 与对应样例的字段顺序和标点一致，包含适用DOI，不臆造卷期页。

### AC-US-19-02

Given 记录为软件著作权或专利。

When 生成引用。

Then 明确类型并使用适用登记号或专利号，不使用论文卷期页。

### AC-US-19-03

Given 出处或年度未知。

When 生成引用。

Then 缺失字段不虚构；显示待补提示，机器格式省略未知可选字段。

### AC-US-19-04

Given 浏览器拒绝剪贴板访问。

When 点击复制。

Then 回退为可选中文本框并提示手工复制。
