# US-22 订阅与引用提醒

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望订阅条件或本人成果引用变动，以便减少重复查询。
- 优先级：Could（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3 Could故事及教师需求推演；可选增强不作为首版必验。
- SRS对应：FR-22。

## 业务规则

可选功能；如启用默认每日摘要，只发送新发生且订阅者有权读取的事件，取消订阅立即生效；数据中断后不补发历史积压事件，不承诺全网即时提醒。

## 验收标准

### AC-US-22-01

Given 可选模块启用且订阅条件匹配。

When 有新的可读成果发布。

Then 每日摘要含题名和链接，受限成果不出现在通知中。

### AC-US-22-02

Given 本人成果有新的已核验平台引用边。

When 下一摘要批次。

Then 生成带来源的新增引用提醒。

### AC-US-22-03

Given 用户取消订阅。

When 后续匹配成果发布。

Then 不再产生该订阅通知。

### AC-US-22-04

Given 引用数据暂不可用后恢复。

When 重新展示或推送。

Then 显示获取时间，不补发旧事件、不显示全网即时覆盖。
