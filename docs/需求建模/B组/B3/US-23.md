# US-23 保存检索与收藏

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望保存检索条件和收藏成果，以便便于再次使用。
- 优先级：Could（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3 Could故事；个人数据规则来自B4建议。
- SRS对应：FR-23。

## 业务规则

可选增强。每账号最多50个保存检索条件、500条收藏；数据私有，不用于公开排序。保存条件复现按当前数据与权限执行，不承诺结果快照完全相同。

## 验收标准

### AC-US-23-01

Given 已保存一个检索条件。

When 再次使用。

Then 还原条件并按当前数据重新执行，不把历史权限当作当前权限。

### AC-US-23-02

Given 收藏3条当前可读成果。

When 打开收藏。

Then 按收藏时间列出可读条目且可进入详情。

### AC-US-23-03

Given 收藏成果后来不可见或删除。

When 打开收藏。

Then 显示不含原标题的已失效占位，可删除收藏，不泄露旧内容。

### AC-US-23-04

Given 访客未登录或保存数量超限。

When 尝试保存。

Then 提示登录或对应上限，不写匿名历史或超额数据。
