## 统一口径与核对结果

1. 作业 1 的公开走查只实测论文、专利、项目、获奖四类样本；作业 2 的 **七类成果** 是 B 组 SRS V1.1 的设计与验收范围，不能据此声称七类均已取得真实样本。未发表手稿不从公开网页采集，只能按授权登记和访问。
2. 用例模型保持 **UC01—UC06 六个核心用例**；七类成果是数据类型，不是七个用例。FR-29 专家合作网络作为 UC06 的扩展流程，追溯到 AT-17。
3. SRS、SPEC、A3 清单及本 PPT 均采用同一范围。SPEC 已从旧 V1.0 基线调整到 **SRS V1.1**；A3 已更正 OpenAlex/DBLP 五条已知 DOI 小样本的实测状态和公开内容变更审核规则。
4. CodeArts ZIP 是可编辑模型工程，PNG 是导出预览。图、规约与验收场景是**设计交付**，不表示系统已实现或验收测试已通过。
5. 教师、科研秘书和管理员尚无真实访谈；B5 的角色诉求为 AI 推演。学校实际审核岗位、逐源采集许可及其他三类成果的逐件授权仍待业务核验。
