# UC06 查看成果统计与专家合作网络

**版本**：v1.0　**负责人**：A5　**基线**：A2 用例图中 UC06、B1《SRS》FR-28/29、IF-13、DR-01/04、NFR-03/12、AT-16/17　**优先级**：Must

| 项目 | 规约 |
| --- | --- |
| 主参与者 | 访客（ACT01）；平台管理员（ACT04）可在授权范围内查看管理统计 |
| 目标 | 按明确的机构、领域、年份和类型口径查看平台可读成果统计，并交互探索由共同署名形成的专家合作网络 |
| 触发 | 用户打开统计页或合作网络入口，选择筛选条件 |
| 前置条件 | 平台有可查询的成果、作者 Person、机构和学术领域映射；统计服务可用。无数据时仍可展示可理解的空状态 |
| 成功后置条件 | 页面展示可复算的按类型/年度/领域/机构统计与数据范围、生成时间、去重和年度口径；合作网络展示可公开人员、共同成果边权、筛选结果及有权查看的路径或“无路径” |
| 最低保证 | 不把平台入库量冒充机构全部成果或权威评价；不可读成果和未公开身份不计入当前用户的统计、图、节点详情或路径 |

## 主成功流程

1. 用户打开统计页，平台识别身份与授权，显示默认统计范围、数据更新时间和机构/领域/类型/年度筛选项；年度默认按 `publication_year`，未知年份单列。
2. 用户选择条件，平台先过滤当前用户可读且已发布的成果，再按稳定 `achievement_id` 去重，计算年度数量、机构按类型数量/排名、领域关键词热点与人员合作概览。
3. 平台展示每张图/表的机构范围、年度口径、起止时间、数据来源范围、去重规则及生成时间。多机构合作成果在每个相关机构可贡献 1 条，但平台总量不把各机构数相加。
4. 用户进入专家合作网络。平台以有权读取的已发布成果和可公开学者 Person 为节点，以共同署名的成果为边；边权为两人共同成果去重数，不以姓名相同生成节点合并，也不把共著等同现实好友关系。
5. 用户按机构、领域、年度筛选网络，点击节点/边查看对应的有权成果与证据；平台在相同可读子图上计算两节点间最短合作路径并显示路径及支撑成果，若无路径明确提示。
6. 用户修改筛选条件或权限发生变化时，平台重新计算可读范围和结果，不从旧缓存/旧路径泄露已经不可读的成果或人员。

## 备选与异常流程

| 编号/接入点 | 条件 | 系统行为与结果 |
| --- | --- | --- |
| A1／步骤 2 | 当前范围无已发布可读成果或某年度未知 | 显示“无数据”及当前范围；未知年度另列，不伪装为 0 年或用来源列表日期填充 |
| A2／步骤 2—3 | 来源覆盖不足、缺机构/领域映射或统计口径有冲突 | 显示可计范围和缺失/待核验数量，必要时标明无法计算；不把部分数据称全量排名 |
| A3／步骤 2—5 | 统计/图计算服务超时或失败 | 显示计算失败与可重试入口、请求 ID；不把错误当作真实零数量或无路径 |
| A4／步骤 4—5 | 合作作者同名、未核验身份或存在 private/members 成果 | 依稳定 Person ID 和可读成果建图；不自动合并同名；不可读成果不计边权、不显示证据 |
| A5／步骤 5 | 两个可读节点在当前过滤后的图中没有连接路径 | 明示“当前条件下无合作路径”，保留筛选范围；不推断二人从未合作 |
| A6／步骤 6 | 权限收窄、成果下架或可见范围改变 | 即时撤销相关统计、节点、边和路径的读取；重新计算或使旧结果失效，不沿用旧缓存 |

## 业务规则与数据要求

- BR-UC06-01：统计只基于平台当前可读且已发布记录，按调用者权限计算；七类成果均在类型维度内，是否有数据与是否支持类型分开。
- BR-UC06-02：平台总成果数按 `achievement_id` 去重；多机构按类型计数可各记 1 条，展示口径时不得把机构计数直接相加当总量。
- BR-UC06-03：年度默认 `publication_year`，来源分组年度需明确指定来源；未知单列，不静默替代。
- BR-UC06-04：合作网络仅表示可读已发布成果的共同署名，节点来自可公开 Person，边权为共同成果去重数；最短路径在当前过滤子图上计算。
- BR-UC06-05：合作网络是 B1 SRS 的首期必验创新功能，由 A2 图的 UC06 作为统计分析入口承接；A1 追溯中明确 FR-29 → UC06 → AT-17。

## 可验收场景

1. **统计口径**：给定一条跨两机构合作成果；当统计两个机构及平台总量；则各机构可各计 1，平台总量按成果 ID 只计 1，并显示口径（AT-16）。
2. **权限过滤**：给定公开、members 和 private 成果；当访客查看统计与合作图；则只计其可读记录，不从边权或路径泄露不可读内容（AT-16/17）。
3. **最短路径**：给定 A-B、B-C 的可读共著边且无 A-C 边；当查询 A 到 C；则返回 A-B-C，并能打开有权证据；过滤掉 B-C 后提示当前条件下无路径（AT-17）。
4. **无数据与失败**：给定空结果和服务故障；当分别请求；则一个是“当前范围无数据”，一个是“计算失败”，均保留筛选范围且不宣称全网结论。
