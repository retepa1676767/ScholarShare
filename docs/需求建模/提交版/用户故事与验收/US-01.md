# US-01 上传学术成果

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：学生或教师等认证成员
- 用户故事：作为学生或教师等认证成员，我希望提交自己的学术成果，以便集中管理并在审核后展示。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：负责人分工中的上传管理链；B2原稿；任务书成果维护要求。
- SRS对应：FR-01。

## 业务规则

先保存草稿再提交；只有通过服务端校验且附件完成安全检查的版本可送审。有符合条件的署名教师时进入初审，否则直接进入管理员复审；未审核记录不公开。

## 验收标准

### AC-US-01-01

Given 认证成员已登录并填写全部必填字段。

When 点击提交。

Then 系统生成待初审或待复审记录，在我的成果中显示对应状态及提交版本号。

### AC-US-01-02

Given 提交成功。

When 打开消息中心。

Then 显示提交成功及当前审核阶段，不显示已经发布。

### AC-US-01-03

Given 有必填项为空。

When 尝试提交。

Then 系统逐项提示缺失字段且不创建审核任务。

### AC-US-01-04

Given 访客未登录。

When 访问上传页或调用创建接口。

Then 要求登录且不写入业务数据。
