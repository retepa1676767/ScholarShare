# US-03 元数据校验

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：认证成员
- 用户故事：作为认证成员，我希望获得字段校验和缺失提示，以便减少不可检索和错误数据。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B4的20条样本记录支持DOI和关键词缺失状态；只说明该样本页面字段，不外推全部成果。
- SRS对应：FR-03。

## 业务规则

人工提交必填题名、至少1位作者、类型和四位成果年度；来源导入的历史年份未知时可入草稿，但不可提交公开审核。DOI及关键词可空；前后端双重校验以服务端为准。

## 验收标准

### AC-US-03-01

Given 题名、作者、类型或年度缺失。

When 人工提交审核。

Then 被阻止且按字段显示原因。

### AC-US-03-02

Given 年度填写去年等非四位年份内容。

When 触发校验。

Then 显示四位年份提示，校验不通过且提交被阻止。

### AC-US-03-03

Given 论文DOI为空或填写错误格式。

When 执行校验。

Then 空值可通过，错误格式被指出；语法通过不显示已验证真实性。

### AC-US-03-04

Given 合法记录已审核发布。

When 按题名、作者和成果年度检索。

Then 有权用户能够命中该记录。
