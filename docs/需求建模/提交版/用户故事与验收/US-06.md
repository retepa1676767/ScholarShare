# US-06 教师初审

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：具有初审权限的教师
- 用户故事：作为具有初审权限的教师，我希望审核相关署名成果，以便核对署名和成果内容。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B5 T-01角色推演及反方意见；属于推演，不冒称真实访谈。
- SRS对应：FR-06。

## 业务规则

初审绑定提交版本。任何一位合格署名教师通过可进入管理员复审；所有初审人及提交者获通知，未操作者不能显示为已通过。全部拒绝才退回；无合格初审教师则直接管理员复审。初审意见不是最终发布许可。

## 验收标准

### AC-US-06-01

Given 署名含有初审权限的教师T。

When 成员提交该版本。

Then T的待审队列显示该版本及附件授权信息。

### AC-US-06-02

Given 教师对当前版本通过。

When 保存意见。

Then 状态变为待复审，进入管理员队列并通知提交者。

### AC-US-06-03

Given 教师拒绝但理由为空。

When 确认拒绝。

Then 操作被阻止且要求填写理由。

### AC-US-06-04

Given 所有分派教师均已拒绝且记录理由。

When 最后一份拒绝意见保存。

Then 记录退回，提交者可修改并重新提交，拒绝原文可查看。

### AC-US-06-05

Given 初审人T1与T2且仅T1通过。

When 完成T1意见。

Then 进入待复审并通知T2；T2意见仍是未操作，不伪造其背书。
