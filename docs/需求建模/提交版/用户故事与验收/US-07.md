# US-07 管理员复审与下架

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：具有终审权限的平台管理员
- 用户故事：作为具有终审权限的平台管理员，我希望复审并发布或下架成果，以便控制对外展示和处理争议。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B5 M-01推演、B2原稿；B5退回验收补充。
- SRS对应：FR-07。

## 业务规则

终审人与提交者不得相同；当署名或利益冲突时转另一授权管理员。退回必须有理由，重新提交重新初审；恢复下架需复审和记录原因。

## 验收标准

### AC-US-07-01

Given 成果待复审且管理员无利益冲突。

When 确认发布。

Then 当前审核版本进入已发布，按范围可见，提交者获通知。

### AC-US-07-02

Given 记录已发布。

When 填写理由并确认下架。

Then 公共检索、详情、附件和导出立即不可读，状态已下架并发送通知。

### AC-US-07-03

Given 下架或退回没有理由。

When 确认操作。

Then 服务端拒绝，不产生状态变化。

### AC-US-07-04

Given 管理员打开操作记录。

When 查询发布、退回和下架。

Then 显示操作者、时间、版本、理由与结果。

### AC-US-07-05

Given 成果待复审。

When 管理员退回并填写理由。

Then 状态退回，提交者收到理由；修改后按当前规则重新送审。
