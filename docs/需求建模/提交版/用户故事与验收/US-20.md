# US-20 批量导出

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：有读取权的用户
- 用户故事：作为有读取权的用户，我希望导出选中成果或全部筛选结果，以便用于引用与汇总。
- 优先级：Must（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3原稿与B4 IF-10；单次上限以整合规则统一。
- SRS对应：FR-20。

## 业务规则

输出UTF-8 CSV或BibTeX，单次最多1000条，不导出附件。按调用时权限与当前发布版本筛选；仅统计有权对象，缺失字段不填虚构占位值。

## 验收标准

### AC-US-20-01

Given 勾选15条完整论文。

When 导出BibTeX。

Then 得到15个唯一键且可解析的记录，无字段乱码。

### AC-US-20-02

Given 筛选共300条而页面仅20条。

When 选择全部命中导出CSV。

Then 导出全部300条而不是当前页，显示实际条数。

### AC-US-20-03

Given 选中项包含权限已撤销的记录。

When 执行导出。

Then 跳过无权项，仅返回总跳过数，不返回其题名或内容。

### AC-US-20-04

Given 历史记录缺年份或超过1000条。

When 分别执行导出。

Then 缺年份项保留可用字段并提示；超限请求要求分批且不生成不完整成功文件。
