# US-21 引用链与来源

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：访客或认证成员
- 用户故事：作为访客或认证成员，我希望查看可核验的施引和被引关系，以便追溯关联成果。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3 US-21；范围为平台内/授权文件记录，不保证全网覆盖。
- SRS对应：FR-21。

## 业务规则

引用边必须来自明确的参考文献关系或授权引用文件；A自己的DOI不是A引用B的证据。同名比对仅产生待核验候选，不直接形成确定引用边。首版不实时同步收费库或Google Scholar。

## 验收标准

### AC-US-21-01

Given A的已核验参考文献明确指向B的DOI。

When 查看B详情。

Then 引用本文列出有权查看的A并标来源和获取时间。

### AC-US-21-02

Given 授权CSV文件导入外部引用记录。

When 展示关系。

Then 区别平台内关系与外部来源，不混称全网被引。

### AC-US-21-03

Given 记录无可用引用数据。

When 打开详情。

Then 显示暂无引用数据而非0次被引。

### AC-US-21-04

Given 引用指向未收录成果。

When 点击该引用。

Then 显示可公开的来源说明和收录建议入口，不跳空白内部页面。
