# US-24 许可附件全文检索

版本：V1.0 整合终版；日期：2026-10-12。

- 角色：访客或认证成员
- 用户故事：作为访客或认证成员，我希望检索有权读取的PDF正文，以便通过内容找到成果。
- 优先级：Should（保留组员故事分级；课程必做要求另在SRS标明）。
- 来源：B3 US-24及B4安全、权限约束。
- SRS对应：FR-24。

## 业务规则

首版支持已发布且通过安全检查的有文本层PDF；扫描件不做OCR，不提供来自不可读附件的片段。private草稿仅在所有者私人工作区可查，不进入公共搜索。

## 验收标准

### AC-US-24-01

Given 已发布且允许读取的PDF有文本层。

When 检索正文中的词。

Then 返回正文命中标记和可读片段。

### AC-US-24-02

Given 附件为无文本层扫描PDF。

When 检索仅出现在图片里的词。

Then 不产生正文命中并说明未启用OCR。

### AC-US-24-03

Given private记录已发布但仅责任人可读。

When 他人与责任人分别检索。

Then 他人不命中；责任人按本人可读范围可命中。

### AC-US-24-04

Given 附件权限不允许用户读取。

When 检索正文或使用旧索引。

Then 不返回该附件片段或靠该附件产生的命中。
