## 支撑证据

`证据材料/A组/` 包含匿名化的 20 份问卷答卷、统计小结、图表、A2—A5 走查记录和截图；`证据材料/B组/` 包含七渠道竞品矩阵、B4 存量抽样及截图、B5 角色推演和反方评审。匿名化答卷已去除 IP、设备 UA、地理位置及平台自定义字段；原始文件保留在工作目录，不放入提交版。

## 最终提交前填写

在报告封面及 PPT 首页填写小组编号、名称、联系人和成员信息。参考模板要求十名成员的本次作业占比合计处于 95%—105%。如课程平台要求单文件上传，可将本文件夹压缩后提交。

## 证据边界

本轮有普通用户问卷和公开来源走查；没有教师或管理员真实访谈。作业 1 的公开样本覆盖论文、专利、项目、获奖四类；作业 2 按 B 组 SRS 建模七类成果。两种范围在报告和 PPT 中分别标明。
